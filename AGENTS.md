# Agent instructions

## Battle HUD

- Battle HUD textures are generated by `tools/ui/generate_hud_kit.py` (one kit per faction under `assets/ui/hud/<faction>/`); change the generator profiles instead of editing the PNGs.
- Review visual HUD changes with `tests/rendered/HudConsolePreview.gd` (run without `--headless`), which writes captures for every faction to `art/hud-console/`.

## Saves and tests

- Battle saves accept only the current `MatchSnapshot.VERSION`; there is no migration code. When the version changes, convert the archived saves in `docs/playtests/` and `tests/fixtures/` while preserving their unit and resource IDs, because tests reference them directly.
- Test scripts run with `--script` compile before autoloads exist. Use `load()` at runtime, not top-level `preload()`, for `source/` scripts that use autoload singletons (`MatchSignals`, `Utils`, `Constants`, `Globals`).

## Localization

- Edit `art/localization/*.tsv`, then run `python3 art/localization/build_catalog.py`; do not edit `assets/translations/ui.csv` directly.
