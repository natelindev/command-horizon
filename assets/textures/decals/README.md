# Ground decals

Original procedural artwork generated by `tools/textures/generate_ground_decals.py`
(fixed seeds; rerun to reproduce exactly). Color is neutral gray and alpha holds
coverage; `source/match/effects/GroundDecals.gd` tints them per biome.

- `oil_stain_a/b`: irregular dark stains with speckled edges.
- `tire_tracks`: two curved tread bands.
- `skid_marks`: two dark rubber streaks.
- `cracks_a/b`: long branching fractures for paved maps.
- `repair_patch`: sealed asphalt patch with tar seams.
- `debris`: scattered light and dark stones.
- `scuff`: light, disturbed-ground patch.

Placement is seeded by the map scene, so a map and its restored saves always show
the same decals. They project only onto the ground render layer (11, "Ground
decals"), never onto units, structures or water, and stay inside the battlefield.
