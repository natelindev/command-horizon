# 战斗界面美术统一

## 目标
沿用启动首页的工业科幻美术、炭灰色、金色细边和象牙白文字，让战斗 HUD 与弹窗拥有统一、精致的游戏界面质感。避免层层矩形卡片，保留原生文字、键盘焦点、交互语义及缩放行为。

## 阶段
1. 检查首页、战斗布局和现有验证脚本，生成可实际使用的 imagegen 面板材质与指挥舱插画。
2. 建立共享战斗主题，接入资源、指挥、单位、小地图、字幕、科技、程序和存档界面。
3. 运行解析、样式检查与渲染交互验证，检查中英文、720p / 1080p 和界面缩放，保存截图。
4. 根据金边首页与警报截图反馈，精修开放式列表、单位标签页、插画暂停菜单及小窗口布局，补充导航与悬停验证。
