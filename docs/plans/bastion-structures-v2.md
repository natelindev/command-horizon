# Bastion 建筑重设计与地基耐久修复

## 阶段

1. 修复新建筑仅有 1 HP 的问题：地基初始拥有 25% 最大生命值，余下耐久随施工增长；保留敌方伤害、施工中禁用功能、取消退款及存档语义。
2. 重做九种 Bastion 建筑：统一重装工业风格，以堡垒、拱形营房、开放装配厂、停机坪、反应堆、雷达、维修龙门和两种武器平台形成不同轮廓。输出可编辑 Blender、GLB 和由真实模型渲染的图标。
3. 将旧非武装建筑用于地图边缘的中立工业区，替换游戏内建筑模型和建造图标，核对碰撞尺寸及炮塔关节。
4. 验证初次受击、持续攻击、施工完成、伤害保留、存档恢复与取消退款；运行相关回归和实际游戏渲染检查。
