# 简体中文与英文 UI

## 阶段

1. 建立简体中文/英文翻译目录和统一语言设置，兼容已有选项文件，打包可跨平台使用的思源黑体字体。
2. 覆盖菜单、设置、故事、阵营、战役、HUD、建造、科技、程序编辑、保存/载入和提示。动态数值及组合文本保留格式与键位。
3. 即时切换并持久化语言；取消设置时回退原语言，保留脚本源码、用户名称与存档逻辑标识。
4. 验证中英文布局、中文字符、动态 HUD、语言往返切换、设置持久化、主要交互及相关回归。
