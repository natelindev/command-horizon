# Campaign storyline verification

The six operations now tell one continuous story: a relief convoy opens the road; First Orders reconnects command; Split Signal intercepts a rescue request; Air Corridor extracts engineers; Broken Foundry stops armored production; Command Horizon ends the offensive. Each mission has a voiced opening, relevant gameplay milestones, and a victory transition. Shared narration explains functioning enemy factories and the finale siege commander. There are 26 English/Chinese pairs with actual Hugging Face neural audio recordings (52 WAVs; 590.6 seconds). English uses Kokoro v1.0 `af_heart`; Mandarin uses Kokoro v1.1-zh `zf_001`. Both weight sets match the official model-card SHA256 values. The initial operating-system voice draft was replaced completely.

Opening briefings animate the existing isometric camera over the existing world and freeze simulation. The existing HUD is hidden during presentation and restored afterward. The immediately focused Continue/skip control, Enter, Space, and Escape skip; the skip key release is consumed so it cannot also toggle tactical pause. The original camera transform, zoom, processing, focused control, input processing, HUD visibility, and prior pause state are restored. Existing reduced-motion options disable camera movement. Mission actions, resources, health, navigation, and fog are untouched by storytelling.

Gameplay narration runs through the existing subtitle card, subtitle size/toggle, language settings, Voice volume and radio audio bus. Unit chatter is suppressed only while narration is playing; it returns afterward. Milestones are observed from mission state, rather than changing objective mechanics. Heard/queued cue IDs are stored once in the match save; restored legacy battles skip the opening and already-reached milestones.

Verification:

- `CampaignStoryRegression.gd`: zero failures. Checks every EN/CN audio stream, subtitle content, camera animation, simulation/resource/order freeze, keyboard skip and release, previous tactical pause, exact camera restoration, reduced motion, chatter recovery, duplicate cues, victory priority, legacy cue restoration, strict rejection of unknown narration IDs, and a real checksummed disk save/load that retains narrative history without replaying speech.
- `CampaignStoryMissionsRegression.gd`: zero failures. Starts all six actual scenes, verifies correct opening audio, runs forced animated briefings, observes mission state, and skips back into each battle. Activating the actual Air Corridor enemy base emits base narration without fictional boss-arrival/defeat cues. Killing the actual Horizon commander before its first barrage still emits its defeat cue.
- Rendered `tests/rendered/CampaignStoryPreview.gd`: zero failures at 1280×720, English and Chinese (26 px subtitles, 150% interface setting). Both briefing rectangles fit the viewport; mouse skip resumes the match. Four constructed victory displays (First Orders and Command Horizon × English and Chinese) at 150% also fit the viewport, retain action-button keyboard focus, and support keyboard scrolling of the debrief/telemetry body. Narrative endings remain readable in the persistent mission debrief. Screenshots are included. This uses engine-injected input in the actual Godot renderer.

Commands use Godot 4.6 at `tmp/tooling/godot-4.6/Godot.app/Contents/MacOS/Godot`, `--headless --path . --script tests/headless/CampaignStoryRegression.gd` (or `CampaignStoryMissionsRegression.gd`). Rendered verification uses `--rendering-method gl_compatibility` without `--headless`.

The headless path plays voice cues without an invisible modal camera presentation; tests explicitly force the same cinematic code used in rendered campaigns. Engine shutdown resource/texture leak warnings are retained in raw logs. Tests establish behavior and audio availability, not human evaluation of the synthesized performances. Save integration and full campaign outcomes are verified with the broader mechanics work.

Hugging Face generation validation: 52 clips verified and installed; a second install changed zero files. A partial two-clip sample batch was rejected before any asset replacement. All 52 clips are mono 24 kHz, 16-bit PCM with source/file hashes, bounded duration, non-silent RMS, and no PCM clipping. An independent Whisper-base transcription of the English First Orders sample matches the full script; the Mandarin transcription recovers the sentence sequence with homophone substitutions. This is intelligibility evidence, not a substitute for human listening. Model IDs, revisions, licenses, voice embeddings, speed curves, seeds and package versions are recorded in `assets/audio/campaign/generation-manifest.json`; the repeatable build CLI is `tools/audio/generate_campaign_narration.py`.

The original result panel clipped at the 853×480 logical viewport created by 1280×720 at 150%. The same rendered case now passes. The existing result UI is built by `SkirmishResults.gd` with bounded panel dimensions and a scrollable body, keeping its banner and action buttons visible and preserving its existing art/style. The result-builder extraction also keeps `SkirmishHUD.gd` below its lint size limit.
