# Track and wheel teleport guard

Ordinary travel of one metre or less cannot exceed the existing `max(1, speed × delta × 4)` teleport threshold. TrackMotion and WheelMotion now query live movement speed only when the unchanged `distance_to` result exceeds one metre. The original `maxf` expression and strict comparison remain intact; there is no squared-distance approximation, cadence change, native API change or travel-state change. TrackMotion still advances its previous transform before returning for a nonpositive delta.

The original sources/hashes are retained in [baseline.json](baseline.json). The [expected baseline counter failure](baseline-cohort.log) records 8,000 getter calls in 8,000 ordinary articulation advances. Updated [scripted](guard-fallback.log) and [native-flag](guard-native.log) focused checks record zero calls with the same travel phases. The synthetic 200-body fixture checks gameplay-position invariance and 14 edge cases: adjacent float32 one-metre values, exact/adjacent speed thresholds, reverse travel, turning, vertical displacement, genuine teleports and nonpositive deltas. Its fake unit getter counts queries; it is not a full-game timing benchmark.

Actual three-faction UnitAnimationRegression and DecoupledPoseRegression pass in both scripted and native modes. Native fixtures require the unit store and crowd runtime; decoupled coverage additionally uses resident native pose rigs and presentation. NativePoseRigRegression passes 800 transform/hierarchy steps. All [commands/logs](checks.json) and [final hashes](results.json) are retained. Formatting/lint pass. No graphical runs or compilers were launched for this change.

The diagnostic measured editor frame at `low-native-editor-script-profile.log:5138` reported TrackMotion.advance 1.360 ms inclusive / 1.036 ms self across 207 calls, movement-speed getters 0.436 ms inclusive across 218 calls, and movement_technology_factor 0.533 ms across 1,054 calls. Those nested figures must not be added. This change removes unnecessary queries; no complete-frame timing gain or strict MI12 pass is claimed.
