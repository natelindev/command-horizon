# Minimap and selection query reuse

The retained actual 200-tank editor sample at [line 5138 of the profile](../../../../build/verification/macos/tactical-rendered-20261102T054441Z-58184/low-native-editor-script-profile.log) measured Minimap `_process` at 1.223 ms, including its 1.038 ms marker sync, and Selection `_process` at 1.015 ms across 200 selected units, including 0.469 ms in `_on_elevated_ground`. These are nested caller spans from one diagnostic frame, not additive costs or a qualified performance result.

The implementation resolves a fresh valid observer list once per minimap refresh. Known own forces take the same ownership shortcut as Battlefield after the existing restore, hidden-body, resource, HP and full-vision guards. Field mines continue through engineering's observation path; hostile cloaked forces continue through live Battlefield detection. Selection caches the parent's fixed property capability and reads the current map into one invocation-local reference. Its live domain, map replacement, terrain replacement, dynamic height and exact position checks, and every-frame animation remain intact. No save fields or presentation cadence change.

[results.json](results.json) records the exact commands, source hashes, durations and eight successful source checks: OwnershipRegression, CombatPresentationRegression, BattleFeedbackRegression and MobileGarrisonRegression, each in fallback and native modes at fixed 60 Hz. Every log has zero failures and no runtime errors, warnings or leak messages. The new Ownership assertions verify one observer resolution per refresh, current owner and spectator changes, freed observers, mine delegation, all early guards, actual Helix camouflage and close detection, and actual Frontier passengers disappearing from off-phase minimap updates across boarding, unloading and immediate remounting. The native ownership fixture explicitly requires actual native state, crowd and visibility bindings when those flags are supplied. The existing presentation checks cover custom dynamic height providers, same-tick movement, map/terrain replacement and faction animation. The existing garrison and feedback checks include paused v22 save/restore and phased marker positions.

No graphical run was launched for this change. A refreshed actual workload profile is still required to quantify its frame-time benefit; these checks establish behavior, not the strict MI12 performance gate.
