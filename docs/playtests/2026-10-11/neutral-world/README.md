# 中立世界：驻扎、战斗与环境表现

## 操作与规则

- 选中步兵，右键可居住的中立建筑，即可接近并进驻；每栋最多 8 人（步兵扩编更新后）。
- 点击己方驻军建筑可选中内部步兵。下达移动命令、停止命令，或点击命令面板中的“撤出建筑”即可撤出。
- 驻军从建筑射击位置开火，获得按建筑占地计算的视野和射程；驻军不能被单独点击攻击，敌军可自动攻击被占据的建筑。
- 坦克等武装单位可以右键攻击中立对象；步兵要攻击无主建筑时，使用“攻击目标”（默认 T）后点击建筑。
- 无主居民、动物、车辆和建筑不进入自动索敌，避免行军时自行破坏城市。
- 货船、吊车、灯塔和炉体可以受损摧毁，但不是步兵驻扎场所。地图边界之外的远景城区仍属于背景布景。

## 表现

居民、狐狸、海鸥、汽车与拖轮都有独立生命值、受惊反应和死亡表现。附近交火会触发逃跑；居民停步张望、膝肘随步态运动，车辆轮胎转动，屋顶风扇持续运转。死亡后分别表现为倒地、跌落、损坏或倾覆下沉，并停止对应环境声源。

建筑倒塌会生成碎墙、屋顶残片、烟尘；驻军分散撤离并损失 35% 最大生命值。残骸保留占地，降低视线遮挡高度。尸体在 20–30 秒淡出，车辆和建筑残骸保留。所有动画服从暂停和当前视野。

重新生成了车辆、居民及狐狸的 GLB 模型，并保留 Blender 源文件和生成脚本。车辆增加倾斜玻璃、轮毂、胎纹和格栅；居民增加面部与关节细节；建筑按原有立面补充灯具、门把、空调、屋顶女儿墙，避免重复覆盖窗户。远景住宅补充窗台、栏杆、雨水管和随风摆动的织物。

## 存档

快照升级为 v11，记录中立生命值、受惊及死亡时间、驻军和驻军位置，并保留针对中立对象的命令和在途弹道引用。旧版存档按原路线恢复环境角色，并初始化新的中立交互状态；伪造生命值、重复驻军、非法席位和不适用建筑的驻军会被拒绝。

## 验证

回归脚本：

- `tests/headless/NeutralWorldRegression.gd`：显式攻击与在途存档恢复、全部中立类型死亡、进驻/满员/敌占/驻守开火、撤出按钮、建筑摧毁、状态往返和非法存档。
- `tests/headless/AmbientLifeRegression.gd`：六张地图的路线、运动、让路、暂停、迷雾与旧存档兼容。
- `tests/headless/CombatRegression.gd`、`DirectOrdersRegression.gd`、`GraphicsRegression.gd`：原有战斗、命令与显示设置。
- `tests/rendered/NeutralWorldPreview.gd`：真实 Metal / Forward+ 渲染，输出同目录的六张检查截图。

最终结果：9 项相关回归通过，未出现脚本解析或运行错误：中立交互、六地图环境、战斗、直接命令、图形设置、存档恢复、建筑基础耐久/旧档迁移、环境音效、武器模式。实际渲染已逐张检查；窗框重叠与完整屋顶压扁的初版效果已修正。

本工作目录最初缺少 Lua 原生扩展，首次通用存档回归因此无法编译测试程序；复用本机已有的 macOS arm64 构建后，重跑通过。构建产物位于被 Git 忽略的 `source/native` 路径，没有写入代码变更。

变更涉及的比赛脚本、设置页和新增测试均通过 `gdformat --check`，`git diff --check` 通过。全量源码格式检查仍有主菜单的 5 个既有文件不符合当前格式器；对 HEAD 原文做相同检查得到同样结果，未扩大修改范围。部分无界面回归退出时仍报告音乐/导航等待状态等资源释放提示；环境音效测试还会有两条预期的“写入失败”日志，用于验证设置保存失败时的恢复行为。
