# Helix Systems — concept-to-model plan

## Stage 1 — Design and concept art

Develop the second faction from the existing Helix Systems proposal: precision, reconnaissance, robots and aircraft; lighter protection and higher electronics costs. Generate key art and complete unit/building reference sheets with the built-in imagegen tool, save exact prompts, and inspect the art before modeling.

## Stage 2 — Blender production

Create eight distinct mobile units and nine structures using the inspected art. Preserve editable component-level Blender source, named rigid pivots, team-color slots, and consistent export axes. Export GLBs, transparent rendered icons, individual review renders and a labeled catalogue.

## Stage 3 — Validation and documentation

Re-import all GLBs and verify geometry, materials, pivots and bounds. Import into Godot and provide an asset review scene. Record faction design, proposed mechanics, asset mapping and implementation limits in the living design document. This task delivers faction design and models; full faction gameplay mechanics are a subsequent integration milestone.
